# Auth.Oauth

## Overview

### Available Operations

* [GetClientConfiguration](#getclientconfiguration) - Read public native OAuth client configuration
* [GetContext](#getcontext) - Read the authenticated OAuth user and workspace

## GetClientConfiguration

Returns the built-in Code registration, or the selected public native client. Available when OAuth is enabled. Does not register clients or grant access.

## GetContext

Requires an OAuth API access token for this issuer resource. Rechecks the parent session, client policy and workspace membership, returning current effective API scopes. Browser cookies, API keys and ID tokens cannot authenticate this endpoint. No additional permission scope is required. Available when OAuth is enabled.

### Example Usage

<!-- UsageSnippet language="go" operationID="getOAuthContext" method="get" path="/api/v1/authentication/oauth2/context" -->

	mka1 "github.com/MeetKai/mka1-sdks/go"
