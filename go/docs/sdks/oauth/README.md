# Auth.Oauth

## Overview

### Available Operations

* [GetContext](#getcontext) - Read the authenticated OAuth user and workspace

## GetContext

Requires an OAuth API access token for this issuer resource. Rechecks the parent session, client policy and workspace membership, returning current effective API scopes. Browser cookies, API keys and ID tokens cannot authenticate this endpoint. No additional permission scope is required. Available when OAuth is enabled.
