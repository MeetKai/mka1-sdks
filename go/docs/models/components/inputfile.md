# InputFile

Input file content item: File input for document processing. Exactly one of file_data, file_id, or file_url is required; a part with none, with more than one, or with a whitespace-only value is rejected (400). An empty string is read as unset.


## Fields

| Field                                                                                                                       | Type                                                                                                                        | Required                                                                                                                    | Description                                                                                                                 |
| --------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------- |
| `Type`                                                                                                                      | `string`                                                                                                                    | :heavy_check_mark:                                                                                                          | The content type identifier for file input.                                                                                 |
| `FileData`                                                                                                                  | `*string`                                                                                                                   | :heavy_minus_sign:                                                                                                          | Base64-encoded file data for inline file uploads. Mutually exclusive with file_id and file_url.                             |
| `FileID`                                                                                                                    | `*string`                                                                                                                   | :heavy_minus_sign:                                                                                                          | The ID of a previously uploaded file. Mutually exclusive with file_data and file_url.                                       |
| `FileURL`                                                                                                                   | `*string`                                                                                                                   | :heavy_minus_sign:                                                                                                          | An http(s) URL the file is fetched from; any other scheme is rejected (400). Mutually exclusive with file_data and file_id. |
| `Filename`                                                                                                                  | `*string`                                                                                                                   | :heavy_minus_sign:                                                                                                          | The original filename for display and reference purposes.                                                                   |
