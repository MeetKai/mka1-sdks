# CreateWebAgentConnectorRequest

Web chat widget connector configuration. Appearance and origins are fixed at creation; recreate the connector to change them. Visitors are anonymous and every message runs the agent with this API key's identity, so use a dedicated, minimally scoped key for agents with tools.
