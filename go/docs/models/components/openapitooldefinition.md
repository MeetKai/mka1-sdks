# OpenAPIToolDefinition

OpenAPI tool definition: HTTP operations, usually imported from an OpenAPI 3 document, that the gateway calls itself. Each operation becomes a function the model can call; the gateway sends the request to server_url (public addresses only, no redirects followed) with the vault credential, and returns the status and body.
