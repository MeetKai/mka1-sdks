# Ranker

Enable re-ranking; set to 'none' to disable, which can help reduce latency.

## Example Usage

```go
import (
	"github.com/MeetKai/mka1-sdks/go/models/components"
)

value := components.RankerAuto
```


## Values

| Name         | Value        |
| ------------ | ------------ |
| `RankerAuto` | auto         |
| `RankerNone` | none         |
