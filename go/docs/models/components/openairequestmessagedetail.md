# OpenAIRequestMessageDetail

The detail level of the image analysis. 'low' disables high-res mode, 'high' enables it, 'auto' lets the model decide.

## Example Usage

```go
import (
	"github.com/MeetKai/mka1-sdks/go/models/components"
)

value := components.OpenAIRequestMessageDetailAuto
```


## Values

| Name                             | Value                            |
| -------------------------------- | -------------------------------- |
| `OpenAIRequestMessageDetailAuto` | auto                             |
| `OpenAIRequestMessageDetailLow`  | low                              |
| `OpenAIRequestMessageDetailHigh` | high                             |
