# ListInputItemsOrder

The order to return the input items in. 'asc' returns oldest items first, 'desc' returns newest items first. Defaults to 'desc' (newest first).

## Example Usage

```go
import (
	"github.com/MeetKai/mka1-sdks/go/models/operations"
)

value := operations.ListInputItemsOrderAsc
```


## Values

| Name                      | Value                     |
| ------------------------- | ------------------------- |
| `ListInputItemsOrderAsc`  | asc                       |
| `ListInputItemsOrderDesc` | desc                      |
