# ListCompletionFeedbackQueryParamOrder

The order to return feedback entries in by creation date of the underlying request. 'asc' returns oldest first, 'desc' returns newest first. Defaults to 'desc' (newest first).

## Example Usage

```typescript
import { ListCompletionFeedbackQueryParamOrder } from "@meetkai/mka1/models/operations";

let value: ListCompletionFeedbackQueryParamOrder = "desc";
```
