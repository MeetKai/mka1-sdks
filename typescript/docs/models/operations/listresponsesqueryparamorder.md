# ListResponsesQueryParamOrder

The order to return the responses in by creation date. 'asc' returns oldest responses first, 'desc' returns newest responses first. Defaults to 'desc' (newest first).

## Example Usage

```typescript
import { ListResponsesQueryParamOrder } from "@meetkai/mka1/models/operations";

let value: ListResponsesQueryParamOrder = "desc";
```

## Values

