# ImportAgentEvalRunTokens

Token totals for the run, summed over its samples when it finalized. Each is null when nothing reported that figure, which is a different fact from zero and must not render as free.

## Example Usage

```typescript
import { ImportAgentEvalRunTokens } from "@meetkai/mka1/models/operations";

let value: ImportAgentEvalRunTokens = {
  input: 152912,
  output: 50522,
  cached: 127207,
  reasoning: 917901,
};
```
