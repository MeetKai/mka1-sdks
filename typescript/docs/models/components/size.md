# Size

The size of the generated image. 'auto' defers to the model's default.

## Example Usage

```typescript
import { Size } from "@meetkai/mka1/models/components";

let value: Size = "512x512";
```

## Values

```typescript
"256x256" | "512x512" | "1024x1024" | "1024x1536" | "1536x1024" | "1792x1024" | "1024x1792" | "auto"
```
