# TwoFile

The file to include in the message, either as raw data or by reference


## Supported Types

### `components.File1`

```typescript
const value: components.File1 = {
  filename: "example.file",
  fileData: "<value>",
};
```

### `components.File2`

```typescript
const value: components.File2 = {
  fileId: "<id>",
};
```
