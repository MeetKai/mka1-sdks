# DataFiles

Optional Hugging Face data_files value for json/csv/parquet style datasets.


## Supported Types

### `string`

```typescript
const value: string = "<value>";
```

### `string[]`

```typescript
const value: string[] = [
  "<value 1>",
  "<value 2>",
];
```

### `{ [k: string]: components.Three }`

```typescript
const value: { [k: string]: components.Three } = {
  "key": [],
};
```
