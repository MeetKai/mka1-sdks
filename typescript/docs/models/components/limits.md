# Limits

api.md §2 `limits` / `default_limits` on the wire: B.1's `contract.Limits`, with
`max_cost` optional and deprecated in the schema while every response still carries it as a
number (MK1-722, step 1 of MK1-719). The two must otherwise agree field for field.

## Example Usage

```typescript
import { Limits } from "@meetkai/mka1/models/components";

let value: Limits = {
  maxRuntimeHours: 5674.22,
  maxLlmCalls: 407168,
};
```
