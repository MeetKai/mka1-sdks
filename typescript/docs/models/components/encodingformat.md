# EncodingFormat

The format to return the embeddings in. Can be either 'float' (array of numbers) or 'base64' (base64-encoded binary).

## Example Usage

```typescript
import { EncodingFormat } from "@meetkai/mka1/models/components";

let value: EncodingFormat = "float";
```

## Values

```typescript
"float" | "base64"
```
