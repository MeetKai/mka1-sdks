# OpenAIChatCompletionChoice2Detail

The detail level of the image analysis. 'low' disables high-res mode, 'high' enables it, 'auto' lets the model decide.

## Example Usage

```typescript
import { OpenAIChatCompletionChoice2Detail } from "@meetkai/mka1/models/components";

let value: OpenAIChatCompletionChoice2Detail = "auto";
```

## Values

```typescript
"auto" | "low" | "high"
```
