# OpenAIChatCompletionChoice

A chat completion choice generated by the model

## Example Usage

```typescript
import { OpenAIChatCompletionChoice } from "@meetkai/mka1/models/components";

let value: OpenAIChatCompletionChoice = {
  index: 569871,
  message: {
    role: "assistant",
    content: [
      {
        type: "text",
        text: "<value>",
      },
    ],
  },
  finishReason: "content_filter",
};
```
