# VectorStore

A vector store is a collection of processed files that can be used by the file_search tool.

## Example Usage

```typescript
import { VectorStore } from "@meetkai/mka1/models/components";

let value: VectorStore = {
  id: "vs_abc123",
  object: "vector_store",
  createdAt: 1704067200,
  name: "Product Documentation",
  usageBytes: 1024000,
  embeddingModel: "auto",
  embeddingDimensions: 1536,
  retrievalMode: "graph",
  fileCounts: {
    inProgress: 0,
    completed: 5,
    failed: 0,
    cancelled: 0,
    total: 5,
  },
  status: "completed",
  lastActiveAt: 1704153600,
  metadata: {
    "department": "engineering",
  },
  lastUsedAt: 1704153600,
};
```
