# OpenAIChatCompletionChunk2Detail

The detail level of the image analysis. 'low' disables high-res mode, 'high' enables it, 'auto' lets the model decide.

## Example Usage

```typescript
import { OpenAIChatCompletionChunk2Detail } from "@meetkai/mka1/models/components";

let value: OpenAIChatCompletionChunk2Detail = "low";
```

## Values

```typescript
"auto" | "low" | "high"
```
