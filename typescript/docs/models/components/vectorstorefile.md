# VectorStoreFile

A list of files attached to a vector store.

## Example Usage

```typescript
import { VectorStoreFile } from "@meetkai/mka1/models/components";

let value: VectorStoreFile = {
  id: "<id>",
  object: "vector_store.file",
  usageBytes: 298795,
  createdAt: 949291,
  vectorStoreId: "<id>",
  status: "in_progress",
  lastError: {
    code: "server_error",
    message: "<value>",
  },
};
```
