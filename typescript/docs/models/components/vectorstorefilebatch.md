# VectorStoreFileBatch

A batch of files attached to a vector store.

## Example Usage

```typescript
import { VectorStoreFileBatch } from "@meetkai/mka1/models/components";

let value: VectorStoreFileBatch = {
  id: "<id>",
  object: "vector_store.file_batch",
  createdAt: 860481,
  vectorStoreId: "<id>",
  status: "completed",
  fileCounts: {
    inProgress: 816482,
    completed: 627454,
    failed: 456300,
    cancelled: 403251,
    total: 582986,
  },
};
```
