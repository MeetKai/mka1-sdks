# AnalyticsQueryRequestValue

Value to compare. The number 1 differs from the string '1'. Omit for exists and not_exists.


## Supported Types

### `string`

```typescript
const value: string = "<value>";
```

### `number`

```typescript
const value: number = 1284.03;
```

### `boolean`

```typescript
const value: boolean = true;
```
