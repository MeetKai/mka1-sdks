# TwoDetail

The detail level of the image analysis. 'low' disables high-res mode, 'high' enables it, 'auto' lets the model decide.

## Example Usage

```typescript
import { TwoDetail } from "@meetkai/mka1/models/components";

let value: TwoDetail = "auto";
```

## Values

```typescript
"auto" | "low" | "high"
```
