# LivekitTokenRequest

Request parameters for generating a LiveKit room token with LLM configuration, optional STT settings, and optional language.

## Example Usage

```typescript
import { LivekitTokenRequest } from "@meetkai/mka1/models/components";

let value: LivekitTokenRequest = {
  llm: {
    model: "El Camino",
  },
};
```
