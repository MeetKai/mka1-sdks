# OpenAIChatCompletionChunkContent

The content of the chunk. May be a string, content parts, or null.

### `string`

```typescript
const value: string = "<value>";
```

### `components.OpenAIChatCompletionChunkContent2[]`

```typescript
const value: components.OpenAIChatCompletionChunkContent2[] = [
  {
    type: "text",
    text: "<value>",
  },
];
```
