# EvalEmbeddingConfig

Configuration of an `embedding` task: which columns hold the texts and labels, the auxiliary datasets, and the scoring protocol.

## Example Usage

```typescript
import { EvalEmbeddingConfig } from "@meetkai/mka1/models/components";

let value: EvalEmbeddingConfig = {
  kind: "classification",
};
```
