# CompactResponseRequestInput

Text, image, or file inputs to the model, used to generate a response.


## Supported Types

### `string`

```typescript
const value: string = "<value>";
```

### `components.Item[]`

```typescript
const value: components.Item[] = [
  {
    type: "compaction",
    id: "<id>",
    content: "<value>",
  },
];
```
