# ComputeLog

One line of a workload's output, or a system note about the workload. Lines are kept for 7 days, and each job or service keeps at most its newest 100 MB, each line counting as its text plus 400 bytes. Once the limit has deleted lines, the log starts with a system line counting them.

## Example Usage

```typescript
import { ComputeLog } from "@meetkai/mka1/models/components";

let value: ComputeLog = {
  id: "<id>",
  message: "<value>",
  source: "user",
  stream: "stdout",
  timestamp: new Date("2026-10-08T23:42:21.995Z"),
};
```
