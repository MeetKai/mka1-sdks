# UpdateCompletionFeedbackRating

Feedback rating indicating user satisfaction. 'thumbs_up' indicates positive feedback, 'thumbs_down' indicates negative feedback.

## Example Usage

```csharp
using MeetKai.MKA1.Types.Requests;

var value = UpdateCompletionFeedbackRating.ThumbsUp;
```


## Values

| Name         | Value        |
| ------------ | ------------ |
| `ThumbsUp`   | thumbs_up    |
| `ThumbsDown` | thumbs_down  |
