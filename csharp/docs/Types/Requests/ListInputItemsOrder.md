# ListInputItemsOrder

The order to return the input items in. 'asc' returns oldest items first, 'desc' returns newest items first. Defaults to 'desc' (newest first).

## Example Usage

```csharp
using MeetKai.MKA1.Types.Requests;

var value = ListInputItemsOrder.Asc;
```


## Values

| Name   | Value  |
| ------ | ------ |
| `Asc`  | asc    |
| `Desc` | desc   |
