# InputItemListObject

Paginated list object containing input items for a response with cursor-based pagination metadata.


## Fields

| Field                                                                                                                                                           | Type                                                                                                                                                            | Required                                                                                                                                                        | Description                                                                                                                                                     |
| --------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `Object`                                                                                                                                                        | *string*                                                                                                                                                        | :heavy_check_mark:                                                                                                                                              | The object type, always 'list' for paginated list responses.                                                                                                    |
| `Data`                                                                                                                                                          | List<[Item](../../Types/Components/Item.md)>                                                                                                                    | :heavy_check_mark:                                                                                                                                              | Array of input items (messages, prompts, instructions) that were provided when creating the response. Each item contains its type, content, role, and metadata. |
| `FirstId`                                                                                                                                                       | *string*                                                                                                                                                        | :heavy_minus_sign:                                                                                                                                              | The ID of the first item in the current page. Used as a reference point for pagination.                                                                         |
| `LastId`                                                                                                                                                        | *string*                                                                                                                                                        | :heavy_minus_sign:                                                                                                                                              | The ID of the last item in the current page. Used as a cursor for fetching the next page.                                                                       |
| `HasMore`                                                                                                                                                       | *bool*                                                                                                                                                          | :heavy_check_mark:                                                                                                                                              | Indicates whether there are more items available beyond the current page. True if additional pages exist, false otherwise.                                      |
