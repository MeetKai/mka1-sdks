# Style

The style of the generated image. 'vivid' leans toward hyper-real and dramatic. 'natural' produces more naturalistic results. Conditionally supported.

## Example Usage

```csharp
using MeetKai.MKA1.Types.Components;

var value = Style.Vivid;
```


## Values

| Name      | Value     |
| --------- | --------- |
| `Vivid`   | vivid     |
| `Natural` | natural   |
