# ToolChoiceMode

Tool choice mode: Selects how the model decides tool usage. Use none, auto, or required.

## Example Usage

```csharp
using MeetKai.MKA1.Types.Components;

var value = ToolChoiceMode.None;
```


## Values

| Name       | Value      |
| ---------- | ---------- |
| `None`     | none       |
| `Auto`     | auto       |
| `Required` | required   |
