# Severity

Whether an issue stops a consumer (`ERROR`) or is for a human to look at (`WARNING`).

## Example Usage

```csharp
using MeetKai.MKA1.Types.Components;

var value = Severity.Error;
```


## Values

| Name      | Value     |
| --------- | --------- |
| `Error`   | error     |
| `Warning` | warning   |
