# EncodingFormat

The format to return the embeddings in. Can be either 'float' (array of numbers) or 'base64' (base64-encoded binary).

## Example Usage

```csharp
using MeetKai.MKA1.Types.Components;

var value = EncodingFormat.Float;
```


## Values

| Name     | Value    |
| -------- | -------- |
| `Float`  | float    |
| `Base64` | base64   |
