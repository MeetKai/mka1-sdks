# TranscriptionResponse

Response from the transcription endpoint containing the transcribed text, detected language, confidence score, and optional speaker segments.


## Fields

| Field                                                                                       | Type                                                                                        | Required                                                                                    | Description                                                                                 |
| ------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------- |
| `text`                                                                                      | *str*                                                                                       | :heavy_check_mark:                                                                          | The transcribed text from the audio file                                                    |
| `language`                                                                                  | *Optional[str]*                                                                             | :heavy_minus_sign:                                                                          | The detected or specified language code in ISO-639-1 format (e.g., 'en', 'es', 'fr')        |
| `confidence`                                                                                | *Optional[float]*                                                                           | :heavy_minus_sign:                                                                          | Confidence score from 0 to 1 where 1 indicates highest confidence in transcription accuracy |
| `speakers`                                                                                  | List[[models.SpeakerSegment](../models/speakersegment.md)]                                  | :heavy_minus_sign:                                                                          | Speaker diarization segments, returned only when include_speaker_data is true.              |
