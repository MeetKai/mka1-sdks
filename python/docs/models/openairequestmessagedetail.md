# OpenAIRequestMessageDetail

The detail level of the image analysis. 'low' disables high-res mode, 'high' enables it, 'auto' lets the model decide.

## Example Usage

```python
from meetkai_mka1.models import OpenAIRequestMessageDetail
value: OpenAIRequestMessageDetail = "auto"
```


## Values

- `"auto"`
- `"low"`
- `"high"`
