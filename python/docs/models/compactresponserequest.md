# CompactResponseRequest

Request schema for compacting a response's conversation history into a condensed summary.


## Fields

| Field                                                                                                                           | Type                                                                                                                            | Required                                                                                                                        | Description                                                                                                                     |
| ------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------- |
| `model`                                                                                                                         | *str*                                                                                                                           | :heavy_check_mark:                                                                                                              | The model to use for generating the compaction summary.                                                                         |
| `input`                                                                                                                         | [Optional[models.CompactResponseRequestInput]](../models/compactresponserequestinput.md)                                        | :heavy_minus_sign:                                                                                                              | Text, image, or file inputs to the model, used to generate a response.                                                          |
| `previous_response_id`                                                                                                          | *Optional[str]*                                                                                                                 | :heavy_minus_sign:                                                                                                              | The ID of a previous response whose conversation history should be compacted. If omitted, only the provided input is compacted. |
