# Analytics

## Overview

Send events and query event counts or unique visitors.

### Available Operations

* [capture](#capture) - Durably accept a batch of events
* [query](#query) - Query event counts or unique visitors

## capture

Send a batch of events using the project's X-Analytics-Key header. A 202 response confirms the batch is stored; events become available to queries after background processing. Retry with the same idempotency_key and unchanged events if you do not receive a response.

### Example Usage

<!-- UsageSnippet language="python" operationID="analytics_capture" method="post" path="/api/v1/analytics/capture" -->
```python
from meetkai_mka1 import SDK, models
from meetkai_mka1.utils import parse_datetime


with SDK() as sdk:

    res = sdk.analytics.capture(security=models.AnalyticsCaptureSecurity(
        analytics_capture_key="<YOUR_API_KEY_HERE>",
    ), idempotency_key="batch-2026-09-01-001", events=[
        {
            "event_id": "14fb0864-445b-4ed6-8d67-02c93538d668",
            "event_name": "page_view",
            "timestamp": parse_datetime("2026-09-01T12:30:00Z"),
            "distinct_id": "visitor-123",
            "properties": {
                "pathname": "/pricing",
                "plan": "pro",
            },
        },
    ])

    # Handle response
    print(res)

```

## query

Count events or unique visitors in a time range. Optionally filter by event name or properties, group by one property, and split results into hour, day, or week buckets that start on the clock of an IANA time zone, UTC by default. Each bucket is returned as the UTC instant at which it starts. The range includes from and excludes to. Duplicate event IDs are counted once. An unknown time zone returns 400.

### Example Usage

<!-- UsageSnippet language="python" operationID="analytics_query" method="post" path="/api/v1/analytics/projects/{id}/query" -->
```python
from meetkai_mka1 import SDK
from meetkai_mka1.utils import parse_datetime


with SDK(
    bearer_auth="<YOUR_BEARER_TOKEN_HERE>",
) as sdk:

    res = sdk.analytics.query(id="<id>", metric="unique_visitors", from_=parse_datetime("2026-09-01T00:00:00Z"), to=parse_datetime("2026-09-02T00:00:00Z"), event_name="page_view", bucket="hour", timezone="America/Los_Angeles", group_by="pathname", filters=[
        {
            "property": "plan",
            "op": "eq",
            "value": "pro",
        },
    ], limit=100)

    # Handle response
    print(res)

```
