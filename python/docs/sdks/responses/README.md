# Llm.Responses

## Overview

### Available Operations

* [create](#create) - Create an agent-powered response with tool support
* [list](#list) - List all responses with pagination
* [get](#get) - Retrieve response by ID with status and results
* [update](#update) - Update a response
* [delete](#delete) - Permanently delete a response and its data
* [cancel](#cancel) - Cancel an in-progress background response
* [wake](#wake) - Wake a sleeping background response
* [list_input_items](#list_input_items) - List paginated input items for a response
* [compact](#compact) - Compact a conversation

## create

Creates a new AI agent response using advanced language models with autonomous tool usage capabilities.

### Example Usage

<!-- UsageSnippet language="python" operationID="createResponse" method="post" path="/api/v1/llm/responses" -->
```python
from meetkai_mka1 import SDK


with SDK(
    bearer_auth="<YOUR_BEARER_TOKEN_HERE>",
) as sdk:

    res = sdk.llm.responses.create(model="meetkai:functionary-urdu-mini-pak", input="What is the capital of France?", stream=False, store=True, background=False, parallel_tool_calls=True, max_tool_calls=64, truncation="auto", service_tier="auto")

    with res as event_stream:
        for event in event_stream:
            # handle event
            print(event, flush=True)

```

## get

Retrieves a previously created agent response by its unique ID. When stream=true, returns Server-Sent Events for real-time updates on in-progress background responses.

### Example Usage

<!-- UsageSnippet language="python" operationID="getResponse" method="get" path="/api/v1/llm/responses/{response_id}" -->
```python
from meetkai_mka1 import SDK


with SDK(
    bearer_auth="<YOUR_BEARER_TOKEN_HERE>",
) as sdk:

    res = sdk.llm.responses.get(response_id="resp_get123", include=[
        "file_search_call.results",
        "message.output_text.logprobs",
    ], include_obfuscation=False, starting_after=42, stream=False)

    with res as event_stream:
        for event in event_stream:
            # handle event
```
