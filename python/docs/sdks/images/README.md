# Llm.Images

## Overview

### Available Operations

* [create](#create) - Generate images from text descriptions

## create

Creates AI-generated images from text descriptions.

### Example Usage

<!-- UsageSnippet language="python" operationID="createImage" method="post" path="/api/v1/llm/images/generations" -->
```python
from meetkai_mka1 import SDK


with SDK(
    bearer_auth="<YOUR_BEARER_TOKEN_HERE>",
) as sdk:

    res = sdk.llm.images.create(prompt="A serene mountain landscape at sunset with a lake reflection", model="auto", n=1, quality="hd", response_format="url", size="1024x1024", style="vivid")

    # Handle response
    print(res)

```
